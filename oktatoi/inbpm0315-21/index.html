Magas szintű programozási nyelvek 2 (INBPM0315-21)

Itt találod a Debreceni Egyetem, Informatikai Kar "Magas szintű programozási nyelvek 2" (INBPM0315-21) kurzusához készült oktatói jegyzeteinket — saját, tanítás közben összeállított anyagokat, amiket a tanítványainknak írtunk, nem hallgatói jegyzeteket.

Hirdetés

1. Jegyzet — Java fordítási folyamat, alapok

A javac/JVM fordítási folyamat, első Java program írása szövegszerkesztővel és IDE-ben, gyakorló és házi feladatokkal.

2. Jegyzet — Képernyőről beolvasni, tömbök, debug

Bemenet beolvasása Scannerrel, tömbök deklarálása és bejárása, hibakeresés IntelliJ debuggerével, gyakorló és házi feladatokkal.
