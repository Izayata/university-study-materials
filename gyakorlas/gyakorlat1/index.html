1. Gyakorlat — Egyszerű szkript írása

Becsült idő: 30 perc · Nehézség: Könnyű · Frissítve: 2026-09-05

Ez a gyakorlat az 1. jegyzetben telepített környezetre épül. Ha még nem futtattad le a "hello world" példát, előbb tedd meg azt.

Hirdetés

Feladat leírása

Írj egy szkriptet, amely bekér két egész számot, és kiírja az összegüket egy jól olvasható üzenet részeként. 

function osszead(a, b) {
  return a + b;
}

console.log("Az összeg: " + osszead(3, 5));
