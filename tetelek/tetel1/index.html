1. Tétel — Változók és adattípusok

Frissítve: 2026-09-05

Ez a tétel a programozás egyik alapfogalmát, a változót mutatja be, valamint a leggyakrabban használt adattípusokat egy tetszőleges programozási nyelv példáin keresztül.

Hirdetés

A tétel szövege

Mutassa be a változó fogalmát és a leggyakoribb adattípusokat egy tetszőleges programozási nyelvben, példákkal illusztrálva.
Hirdetés

Kidolgozás

Mi az a változó?

A változó egy elnevezett memóriaterület, amely egy értéket tárol, és amelynek értéke a program futása során megváltozhat. A változóhoz egy nevet (azonosítót) és — sok nyelvben — egy adattípust rendelünk.

Alapvető adattípusok

A legtöbb programozási nyelvben megtalálható alapvető adattípusok:

  • Egész szám (integer) — pl. 42
  • Lebegőpontos szám (float/double) — pl. 3.14
  • Logikai érték (boolean) — igaz vagy hamis
  • Karakterlánc (string) — pl. "szöveg"

Példa

let eletkor = 20;          // egész szám
let atlag = 4.5;           // lebegőpontos szám
let aktiv = true;          // logikai érték
let nev = "Kovács Anna";   // karakterlánc

Kapcsolódó fogalmak

  • Típuskényszerítés (type casting)
  • Konstans (nem módosítható változó)
  • Statikus és dinamikus típusosság
